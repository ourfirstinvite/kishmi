# Kishmi — Wedding Invitation

A responsive, static wedding invitation for Kishore and Laxmi. It uses HTML, CSS, and vanilla JavaScript, with Bootstrap's CSS utilities and Google Fonts loaded from their public CDNs.

## Preview locally

Open `index.html` in a browser. For the most reliable media and path handling, serve the folder with any static web server, such as VS Code Live Server.

## Publish free with GitHub Pages

1. Create a public GitHub repository and push the contents of this folder to its `main` branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
4. Wait for the Pages deployment, then use the URL shown in **Settings → Pages**.

No build step is required. Keep the `assets` folder beside `index.html`; the page uses relative asset paths and works from a GitHub project-site URL.

## Included features

- Sealed invitation cover with an open-card transition and falling heart petals.
- Mobile-first layouts, scroll reveals, reduced-motion support, countdown, and audio toggle.
- Reception and muhurtham event details, Google Maps directions, and downloadable calendar events.
- Pre-wedding video, tappable photo gallery, and family blessing section.
